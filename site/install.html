Install RecordCove

These steps are for someone who does not normally install preview software.

Before you start

You need an Apple silicon Mac, macOS 14 or later, about 1 GB of free disk space, and an internet connection. This preview is not yet Apple-notarized.

Private access

  1. Open preview.recordcove.com.
  2. Enter the email address where you want to receive the private access code.
  3. Open the message from Cloudflare and copy the one-time code. Check Spam or Junk if it does not arrive after a few minutes.
  4. Return to the browser, enter the code, and continue. You do not need a GitHub or RecordCove account.

Download

  1. Return to the preview home page and select Download RecordCove for Mac. The download may ask for the same email-code steps because the file is protected separately.
  2. Allow the download if your browser asks.
  3. Wait for it to finish. Open Finder, then select Downloads in the left sidebar.

Check the download

The preview home page displays the exact file name and SHA-256 checksum. If you use Terminal, type shasum -a 256 , drag the ZIP into Terminal, press Return, and confirm the result matches the page. If you do not use Terminal, confirm the browser says the download completed and the file is named RecordCove-macOS-preview.zip.

Unzip and move the app

To unzip means to open the downloaded package so the RecordCove application appears.

  1. Double-click the ZIP in Finder.
  2. Wait for RecordCove.app to appear.
  3. Open a second Finder window and select Applications.
  4. Drag RecordCove into Applications.

First launch

  1. Double-click RecordCove in Applications.
  2. If macOS blocks it, close the message.
  3. Open System Settings, then Privacy & Security.
  4. Find the exact RecordCove blocked-app message and select Open Anyway.
  5. Confirm Open.

Never disable Gatekeeper and never run a command that removes security protection from every download.

Updating later

Finish any recording, quit RecordCove, download the newer preview, then move it into Applications and choose Replace. Your local library is stored separately.
