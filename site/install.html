Install RecordCove

These steps are written for someone who does not normally install preview software.

Before you start

You need an Apple silicon Mac, macOS 14 or later, about 1 GB of free disk space, and an internet connection.

This early preview is ad-hoc signed and is not Apple-notarized. Install it only if you trust Preston Core Systems Limited, downloaded it from preview.recordcove.com, and the filename and checksum match the page.

Download and unzip

  1. Open the Preview downloads page and choose a version.
  2. Wait for the download to finish.
  3. Open Finder and select Downloads in the left sidebar.
  4. Double-click the downloaded RecordCove ZIP. Your Mac creates a folder containing RecordCove.
  5. Drag RecordCove into the Applications folder in Finder.

First launch

  1. Open Applications in Finder.
  2. Hold the Control key while clicking RecordCove, then select Open.
  3. macOS explains that Apple cannot verify the developer. Select Open only if the file and checksum match the Downloads page.
  4. RecordCove should open. If macOS says the app is damaged, stop and tell the maintainer.

Do not disable Gatekeeper and do not run a Terminal command to remove quarantine.

Microphone permission

RecordCove asks for microphone permission only when it needs to record. Select Allow if you intend to record.

Updating later

Finish any active recording, quit RecordCove, open Preview downloads, choose the newer preview, and replace the app in Applications. Your local recording library is stored separately.
