Install RecordCove

These steps are for someone who does not normally install preview software.

Before you start

You will need an Apple silicon Mac, macOS 14 or later, about 1 GB of free disk space, an internet connection for the download, and an invited email address.

The friend download is not open yet. Wait for the maintainer to confirm that the exact build is Developer ID signed, Apple-notarized, and ready. Never use an owner-only ZIP or instructions that ask you to bypass macOS security.

Private access

  1. Open preview.recordcove.com.
  2. Enter your invited email address.
  3. Open the message from Cloudflare and copy the one-time code. Check Spam or Junk if it does not arrive after a few minutes.
  4. Return to the browser, enter the code, and continue. You do not need a GitHub or RecordCove account.

When the download opens

  1. Select Download RecordCove for Mac.
  2. Allow the download if your browser asks.
  3. Wait for it to finish. Open Finder, then select Downloads in the left sidebar.

Check the download

The preview page will display the exact file name and SHA-256 checksum for the friend build. If you use Terminal, type shasum -a 256 , drag the downloaded file into Terminal, press Return, and confirm the result matches the page. If you do not use Terminal, confirm the browser says the download completed and that the filename matches the page exactly.

Open the download and move the app

If the download is a DMG, double-click it, then drag RecordCove onto the Applications shortcut in the window. If the approved format changes, follow the exact steps displayed on this page.

First launch

  1. Open Applications in Finder.
  2. Double-click RecordCove.
  3. Confirm the app opens without an unidentified-developer or damaged-app warning.
  4. If macOS reports either warning, stop and tell the maintainer. Do not select Open Anyway and do not run a Terminal command to bypass the warning.

Updating later

Finish any recording, quit RecordCove, download the newer verified preview, then replace the application. Your local library is stored separately.
